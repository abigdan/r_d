# Lesson-4

## **Базові команди**
Три образи
```
nginx-from-nginx (найбільший за розміром)
nginx-from-ubuntu
nginx-from-ubuntu-with-one-run (найменший за розміром)
```

## **Корисні команди**
```
sudo docker tag nginx-from-ubuntu abigdan/nginx-from-ubuntu:0.2
sudo docker push abigdan/nginx-from-nginx:0.1
```
